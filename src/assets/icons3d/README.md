# 3D icons

Rendered 3D icons in the "premium" finish (gunmetal and gold) from **3dicons** by Vijay Verma — https://3dicons.co, source https://github.com/realvjy/3dicons. Licence: **CC0 1.0** (public domain), free for commercial use, no attribution required.

Each file is the 400 px "dynamic" camera angle, resized to 192 px WebP (quality 88, full alpha) on 4 October 2026. 192 px covers the largest size the app draws (96 px) at 2× pixel density.

The app reaches these files only through `src/components/icons3d/icons3d.ts` (one import per file) and draws them with `<Icon3D>`. `tests/icons3d.test.ts` fails if a file and that list disagree.
